# Security Policy

## Reportando vulnerabilidades

Se encontrar uma vulnerabilidade, abra um issue privado ou entre em contato com
o mantenedor antes de publicar detalhes técnicos.

Não inclua chaves de API, credenciais, dados pessoais ou informações de processos
sigilosos em issues públicas.

## Dados e LGPD

O `pydatajud` apenas facilita consultas à API pública do DataJud. O usuário da
biblioteca é responsável por cumprir os termos de uso do CNJ, a LGPD e quaisquer
regras aplicáveis ao tratamento dos dados consultados.
