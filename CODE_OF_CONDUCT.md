# Código de Conduta

Este projeto busca manter um ambiente técnico, respeitoso e direto.

Comportamentos esperados:

- Discutir ideias e código com civilidade.
- Relatar problemas com contexto suficiente para reprodução.
- Evitar exposição de dados pessoais, credenciais ou informações sensíveis.

Comportamentos abusivos, assédio ou publicação deliberada de dados sensíveis
podem levar ao fechamento de issues, bloqueio de participação ou remoção de
conteúdo.
